# Hot Tub Model Image Manifest

Production hot tub thumbnails must be hosted locally in this repository. Do not hotlink manufacturer or dealer image URLs.

## Required path convention

All model thumbnails use:

`assets/hot-tubs/<brand-folder>/<model-slug>.webp`

Brand folders:
- `american-whirlpool`
- `vita-spa`
- `cal-spas`
- `aquasolus`
- `eco-spas`
- `innova-spas`

Model slug rules: lowercase; spaces and punctuation become hyphens.

Examples:
- American Whirlpool 101 → `assets/hot-tubs/american-whirlpool/101.webp`
- Vita Cabaret → `assets/hot-tubs/vita-spa/cabaret.webp`
- Cal Spas Bel Air Plus → `assets/hot-tubs/cal-spas/bel-air-plus.webp`
- AquaSolus NaturaBalance Aspen → `assets/hot-tubs/aquasolus/aspen.webp`
- Eco Spas E5 DLUX → `assets/hot-tubs/eco-spas/e5-dlux.webp`
- Innova Stream 220V → `assets/hot-tubs/innova-spas/stream-220v.webp`
